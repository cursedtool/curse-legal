Privacy Policy

Last updated: October 9, 2026

1. Scope

This policy describes information processed by Curse when it operates in Discord servers. Processing depends on the features enabled by server administrators and the commands used.

2. Information processed

  • Identifiers: Discord user, server, channel, role, and message IDs where relevant.
  • Moderation data: Warning reasons, moderator IDs, user IDs, timestamps, and relevant action details.
  • Jail restoration data: Prior role IDs and permission overwrite settings needed to restore access.
  • Audit events: If configured, message edits and deletions (including associated message content), member joins and leaves, nickname and role changes, voice-state activity, and server configuration changes.
  • Settings: Enabled logging events and channels, exclusions, access permissions, and warning rules.

3. Purpose

This information is used to perform requested moderation and server-management actions, maintain necessary records, restore permissions after jail, and send enabled audit events to designated Discord channels. It is not used for advertising or sold to advertisers.

4. Storage and retention

Some moderation, jail, and configuration records are stored in Curse's application database. Configuration records are generally maintained while needed for the relevant server features; individual warning records remain until cleared or deleted following a valid request or applicable requirement. Event logs posted in Discord channels are retained there until removed according to Discord's and the server's practices. Curse does not currently provide a universal automatic expiration period for all stored records.

5. Sharing

Moderation records and audit messages may be visible to server administrators and other staff with access to configured channels. Discord processes data as the platform operating the bot and its messages. We do not sell user data. Information may be disclosed if legally required, or processed by infrastructure providers used to operate Curse, when applicable.

6. Data requests and deletion

To request access, correction, or deletion of personal data processed by Curse, email cursebot.support@proton.me and provide your Discord user ID and enough context to identify the relevant server or records. Do not send passwords or login tokens. Requests will be reviewed and data will be removed when required by Discord's developer terms and applicable law. Some audit messages held in a server's Discord channels may need to be removed by that server's administrators or through Discord's processes.

7. Security

Curse uses bot permissions, configured channel access controls, and reasonable operational safeguards intended to reduce unauthorized access. No service can guarantee complete security.

8. Changes

We will update this policy when data-processing practices materially change and revise the date above.
